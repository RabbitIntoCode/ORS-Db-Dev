## Project Overview:

This project demonstrates the design and implementation of an end-to-end modern data engineering pipeline using the following Concepts and Technologies:

**Data Modelling**

**Azure Data Factory**

**Azure Databricks**

**PySpark**

**SQL**

**Jinja**

**GitHub**

It showcases scalable data modeling techniques using Star Schema and normalization (3NF) for efficient and consistent data storage.

It also implements incremental ETL/ELT workflows, dynamic SQL generation using Jinja templates, and Medallion Architecture-based data transformations to process and manage structured datasets efficiently.

You can expect practical examples of data ingestion, transformation, optimization, curated Gold-layer table creation, and business-ready analytical reporting workflows commonly used in real-world cloud data engineering projects.
